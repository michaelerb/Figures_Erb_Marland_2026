# README

Code used to create figures, tables, and some calculations in Erb & Marland 2026: "Global carbon dioxide
emissions from 1750–2022: the CDIAC-FF annual product", available here: https://link.springer.com/article/10.1007/s44246-026-00304-1.

Before running code, you'll probably have to download data and update data and output directories to locations
on your own machine. The main data files for this code are available on FigShare at https://doi.org/10.6084/m9.figshare.31449082.
For some scripts, additional data files are needed; contact Michael Erb at erbm@appstate.edu for details.
